Words you'll see:

- **Beat / bar**: in 4/4 time, a bar has 4 beats. "Bar 3" starts at beat 8 (the song starts at beat 0).
- **Track**: one instrument or recording, shown as a row on the timeline.
- **Clip**: a block on a track holding notes (instrument tracks) or a recording (audio tracks).
- **Loop**: the highlighted region the song repeats while you work. For games, also the finished music file that repeats seamlessly.
- **Stems**: one file per track, so a game can fade instruments in and out.
